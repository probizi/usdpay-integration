# Contributing

Contributions that improve the public API specification, integration examples and developer documentation are welcome.

Before opening a pull request:

1. Keep examples independent of the proprietary USDPAY production implementation.
2. Use placeholder credentials and merchant domains.
3. Run `npm test` with Node.js 20 or newer.
4. Keep API changes aligned with <https://usdpay.me/docs>.
5. Do not include private customer data, production configuration or security-sensitive implementation details.

For substantial additions, open an issue first so the proposed public API behaviour can be discussed.

# Support

## Integration questions

Start with the [API documentation](https://usdpay.me/docs), [webhook guide](https://usdpay.me/webhooks) and the examples in this repository.

For account-specific help, contact **support@usdpay.me** or open the Support section in the [merchant dashboard](https://usdpay.me/dashboard#support).

## GitHub issues

Public GitHub issues are suitable for:

- errors in the OpenAPI specification;
- problems in the public Node.js helper or examples;
- documentation corrections;
- requests for additional public integration examples.

Do not include API keys, webhook secrets, private customer information, wallet recovery phrases or other sensitive data in an issue.

Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md).
